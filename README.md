# Paul Longakit — Portfolio

A single-page static portfolio. To preview it locally, run `python3 -m http.server 8000 --bind 127.0.0.1` from this directory and open <http://127.0.0.1:8000/>.

Edit `index.html` for content, `styles.css` for styling, and `animations.js` for motion. There is no build step. Anime.js loads from jsDelivr; if the CDN is unavailable or the visitor prefers reduced motion, the page remains usable without animations.
